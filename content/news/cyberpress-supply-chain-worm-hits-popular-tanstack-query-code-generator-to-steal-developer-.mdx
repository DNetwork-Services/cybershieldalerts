A supply-chain worm has compromised multiple releases of @7nohe/openapi-react-query-codegen, an npm package that generates type-safe TanStack Query hooks, exposing developer and CI systems to credential theft, repository backdoors, and package poisoning. Aikido Security said it identified 10 malicious versions published within 20 minutes. The package records more than 150,000 weekly downloads, making the incident consequential for developers installing JavaScript dependencies. The payload identifies itself as “Trinitite: Sponsored by Preview 2 Effects,” and researchers said its tradecraft resembles TeamPCP-linked activity, although attribution remains unresolved. Supply Chain Worm Hits Popular TanStack Query Code Generator The compromise reportedly affected both the npm package and its GitHub repository. Attackers are believed to have abused a weakness in a GitHub Actions workflow, meaning releases retained valid provenance attestations. That detail is significant: attestations confirm that a release originated from an authorized workflow, but cannot establish safety when the workflow itself has been altered or compromised. Most affected versions weaponized binding.gyp, a Node.js native-addon build configuration file. During installation, node-gyp evaluates its conditions using Python. Exfiltration repos (Source: Aikido) The malicious file abuses Python’s class hierarchy to locate catch_warnings, regain access to built-in functions, import the os module, and run an obfuscated Node.js payload. No legitimate native build occurs; the configuration exists solely as an installation-time execution mechanism. Some prerelease builds instead used explicit preinstall scripts, while later versions combined both techniques. The primary payload, 3FWCvzduYZg.js, is a 5.4 MB, single-line file layered with XOR, AES-GCM, and JavaScript obfuscation. It silently downloads the Bun runtime before executing credential-harvesting functions. It also checks for Russian locale settings, security-tool directories, known scanner decoy credentials, research accounts, and StepSecurity’s harden-runner, exiting when analysis conditions are detected. Stolen data includes GitHub, npm, PyPI, and RubyGems tokens; AWS, Azure, GCP, and HashiCorp Vault credentials; Kubernetes service account and kubeconfig files; SSH keys; Docker configuration; environment files; Git credentials; shell history; cryptocurrency wallets; messaging session data; VPN configurations; and Claude AI files. Aikido Security said the malware can query cloud metadata services and validate cloud credentials before exfiltration. Collected information is encrypted and committed to attacker-created GitHub repositories, typically named after Touhou Project characters and marked with the Trinitite description. The worm can then use stolen publishing tokens to inject malicious files into packages on npm, PyPI, and RubyGems. With GitHub tokens, it can poison accessible repositories with backdoored VS Code tasks, Claude Code hooks, fake CodeQL workflows, and configuration files targeting other developer tools. Organizations should identify installations of affected versions, revoke and rotate developer, CI, cloud, and registry credentials exposed on systems that ran npm install, inspect repositories for unauthorized commits and configuration files, and review GitHub Actions workflows. Teams should also pin dependencies, enforce least-privilege publishing tokens, and treat provenance as one layer of assurance, not proof that an upstream build pipeline remains uncompromised.
