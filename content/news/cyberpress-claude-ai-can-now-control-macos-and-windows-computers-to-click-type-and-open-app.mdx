Anthropic has expanded Claude’s desktop automation capabilities, allowing the AI assistant to interact directly with macOS and Windows environments through Claude Cowork and Claude Code. The beta capability moves Claude beyond chat-based assistance, enabling it to reliably perform visible, on-screen tasks across local applications, browsers, files, and internal business tools. Once enabled, Claude can examine a visible screen, click interface controls, type text, launch programs, open documents, and work inside browser-based or local software. Claude AI Can Now Control macOS and Windows Computers to Click The feature is intended for situations where a dedicated connector is unavailable, providing users with an alternative way to automate routine desktop work without manually handling every interaction. The capability is available to Pro and Max subscribers using the Claude Desktop application. It gives the model agent-like access to everyday workflows but also introduces security, privacy, and governance questions for organizations considering desktop automation. Computer use requires that the desktop and the Claude Desktop application remain open throughout execution. Claude Cowork uses a hierarchy designed to prioritize precision and speed. It first tries connected services, including Gmail, Google Drive, Microsoft 365, or Slack, because connectors can retrieve information or execute actions more reliably than visual navigation. This approach is intended to limit screen-based interaction when a connection completes tasks. If no connector exists, Claude can use the desktop app’s built-in browser or Google Chrome through Claude in Chrome. Screen interaction is the final option: the model interprets the interface and works as a person would. That enables work within software, dashboards, and applications without requiring integrations, though it&#8217;s slower and error-prone. On macOS 15 and later, Claude can work in background windows, so users may continue using their computers while the agent runs. Anthropic says Claude does not seize the pointer or keyboard and pauses when it detects typing. During a session, it requests permission before it needs full-screen control. Users can choose a full-control setting in the desktop app’s preferences. On both operating systems, Claude needs approval for each application it will interact with. Anthropic also blocks applications by default and supplies an app blocklist, allowing people to deny access to particular software, sensitive activities, or defined business workflows. For security teams, the function creates a high-value permission boundary between an AI agent and a user’s desktop. Claude takes screenshots to understand interfaces, meaning it may view data displayed in applications, including documents and third-party data. There is no sandbox separating the model from the applications it can access. Anthropic says Claude is trained to avoid sensitive data entry, facial image scraping, and investment transactions, but cautions that the safeguards are not foolproof. It scans for prompt-injection indicators during computer use and asks permission before accessing apps. Attackers could attempt to exploit on-screen content, instructions, or links that influence the agent’s actions. The company recommends starting with research tasks, writing prompts, monitoring execution, and avoiding banking, healthcare, government, legal, financial, or other applications that contain personal data. Users should close sensitive files and programs before enabling the feature, as screenshots can capture sensitive information.
