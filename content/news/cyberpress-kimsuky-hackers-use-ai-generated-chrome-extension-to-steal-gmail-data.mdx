North Korea-linked threat actor Kimsuky has been observed targeting organizations in South Korea and Japan with spear-phishing campaigns that combine malicious Windows shortcuts, PowerShell payloads, legitimate remote-access software, and an apparent AI-generated Chrome extension designed to exfiltrate Gmail messages and attachments. According to ENKI, the campaign highlights how Kimsuky is blending commodity tools with tailored malware to sustain access, collect communications, and reduce the chance of antivirus detection. The intrusion begins with phishing emails containing OneDrive sharing links to ZIP archives. Those archives contain malicious .lnk shortcut files disguised as documents, including Japanese-language political material and event-related files. Kimsuky Hackers Use AI-Generated Chrome Extension When launched, the shortcut executes a hidden PowerShell command, opens a decoy PDF to distract the target, downloads a VBScript payload, and runs it from the victim’s AppData directory. The VBScript contacts a command-and-control (C2) server using the infected device’s MAC address as an identifier, then executes a server-provided PowerShell script directly in memory. The initial payload establishes persistence by creating a scheduled task named Chrome_Update, configured to run every 15 minutes. This mechanism enables operators to change the delivered PowerShell code remotely without redeploying the original malware. Attack Overview (Source: enki) Kimsuky’s PowerShell scripts conduct host profiling and collect details of installed security products before exfiltrating the results to attacker-controlled infrastructure. Researchers also identified dedicated collectors for local email clients. A Thunderbird-focused script extracts recent mailbox data from mbox archives and writes individual messages as .eml files. The Outlook collector reportedly gathers inbox and sent items dated from January 1, 2026 onward, saving message content, metadata, and attachments into account-specific directories. A separate keylogger uses inline C# compiled in memory to hook keyboard activity. Keystrokes are written to %AppData%\Microsoft\ttmp1.log, likely for later collection by another script. This approach reduces the attacker’s need to deploy a conventional compiled keylogging binary. The campaign’s most notable component is a malicious Manifest V3 Chrome extension named “Gmail 자동 서버 업로더,” translated as “Gmail Automatic Server Uploader.” The extension requests <all_urls> host access and injects content.js into matching sites. On Gmail pages, it monitors both the compose interface and message-reading pane. When a victim sends or views an email, the script extracts message metadata, content, recipients or senders, and attachment links. Attachments are retrieved through fetch, Base64 encoded, and passed to a background service worker. The background.js component then transmits the stolen data to a C2 endpoint hosted on a free Japanese hosting service. ENKI WhiteHat noted that the extension contains extensive Korean-language comments, debug strings, and Unicode emoji traits that the researchers assess as indicators of generative AI-assisted code production. While these artifacts do not independently prove full autonomous code generation, they suggest operators may be using AI tools to accelerate development of functional browser-stealing capabilities. Kimsuky also abused Chrome Remote Desktop and AnyDesk to retain interactive remote access. In one instance, a script used fodhelper.exe to bypass User Account Control and execute a batch file with elevated privileges, installing Chrome Remote Desktop and binding it to attacker-provided credentials. Another component installed AnyDesk, created a scheduled task for persistence, and attempted to hide AnyDesk windows, taskbar controls, and system-tray indicators. Defenders should investigate unexpected scheduled tasks invoking wscript.exe or PowerShell, unauthorized remote-management tools, unfamiliar Chrome extensions, and extensions with excessively broad permissions. Organizations should also treat OneDrive-delivered archives and disguised LNK files as high-risk attachments, particularly when received through unsolicited or contextually unusual emails. Give your security team the visibility and context to investigate suspicious activity faster and contain threats before business impact grows.
