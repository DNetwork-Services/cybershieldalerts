A TerminalFix campaign, a ClickFix variant, is using fake Cloudflare CAPTCHA prompts to trick users into executing PowerShell commands that install a reverse-tunnel implant. Documented by Microsoft, the activity targets organizations and can turn a compromised Windows device into a network pivot point for attackers. The infection begins on compromised websites that replace content with a convincing Cloudflare Turnstile-style overlay. After a victim clicks the “Verify you are human” prompt, the site copies a malicious command to the clipboard and instructs the user to open Windows Terminal or PowerShell and paste it. Microsoft Warns TerminalFix ClickFix Campaign Microsoft calls the technique TerminalFix because it shifts the familiar ClickFix social-engineering pattern from the Windows Run dialog to Terminal or PowerShell. TerminalFix attack chain (Source: Microsoft) The observed command downloads a ZIP archive, extracts it under a hidden ProgramData directory, and launches a batch file in the background. The archive contains the legitimate signed Windows binary LockScreenContentServer.exe alongside a malicious dui70.dll. Because the executable loads the DLL from its application directory, the attackers use DLL sideloading to run their code inside a trusted process. The DLL then decodes an obfuscated resource in memory and launches a second-stage PowerShell-based payload. That stage retrieves PNG files from attacker-controlled infrastructure and extracts embedded payload data from their pixel channels. It reconstructs an executable and a DLL split across images, then removes the source files. The malware establishes persistence via a Registry Run key and a scheduled task that restarts LockScreenContentServer.exe every 60 minutes. It also hides its ProgramData directory using system and hidden attributes. Microsoft observed the campaign collect system details, enumerate Active Directory users, computers, trusts and domain administrators, and probe likely infrastructure such as domain controllers, databases, backup systems, gateways and mail servers. Most significantly, the operation deploys an embeddable Python runtime and a custom client.py implant launched through pythonw.exe. The implant connects to gitnow[.]dev over TLS on port 443, upgrades the connection to a WebSocket, and relays arbitrary TCP traffic. Fake Cloudflare (Source: Microsoft) Its SOCKS5-style parsing lets the operator direct connections to internal IPv4, IPv6, or hostname targets reachable from the infected machine. Microsoft said it did not observe downstream intrusion actions in the analyzed chain. However, the combination of domain reconnaissance and reverse tunneling means affected endpoints should be treated as potential footholds for lateral movement, credential theft, data theft, or ransomware deployment. Defenders should investigate devices where users interacted with suspicious CAPTCHA prompts or ran unusual PowerShell commands. Priority hunting indicators include LockScreenContentServer.exe launched from paths outside C:\Windows\SystemApps, hidden ProgramData folders, dui70.dll placed beside that executable, suspicious Run keys and scheduled tasks, Python launched with pythonw.exe, and outbound traffic associated with the suspected tunnel infrastructure. Organizations should restrict unnecessary use of PowerShell and Windows Terminal, enable script-block logging, and apply application control policies to prevent untrusted binaries and scripts from executing. User awareness training should also emphasize a simple rule: legitimate CAPTCHA pages never require users to paste commands into a terminal. Any confirmed exposure warrants broad scoping, review for lateral movement, and prompt rotation of credentials accessible from the host.
