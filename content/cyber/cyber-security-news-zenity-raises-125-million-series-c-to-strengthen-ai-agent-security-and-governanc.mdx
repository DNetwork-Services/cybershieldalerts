AI security and governance platform Zenity has announced a $125 million Series C funding round led by Norwest. The investment signals escalating enterprise concern over the security risks associated with autonomous AI agents that access sensitive data, invoke tools, execute workflows, and drive business decisions. Joining lead investor Norwest, new strategic backers Qumra Capital, SoftBank Vision Fund 2, Hitachi Ventures, and LG Technology Ventures participated in the round. Existing investors Vertex Ventures, Third Point Ventures, DTCP, and Intel Capital also re-invested. Zenity Raises $125 Million for AI Agent Security Unlike traditional AI security tools that focus strictly on model protection, static guardrails, or input prompt filtering, Zenity targets the runtime actions of autonomous AI agents operating inside enterprise environments. AI agents are rapidly becoming embedded across software-as-a-service (SaaS) platforms, cloud infrastructure, developer workflows, web browsers, and core business tools. These agents connect directly to critical enterprise resources, including internal email, cloud storage buckets, customer relationship management (CRM) records, calendars, source code repositories, and productivity suites. While this automation offers massive efficiency gains, it creates uncharted attack surfaces. A manipulated or hijacked agent can inadvertently exfiltrate confidential data, trigger unauthorized financial or API workflows, or misuse connected tools. Implementing robust AI security frameworks allows organizations to establish deterministic governance over these non-deterministic agentic systems. Zenity&#8217;s platform provides real-time visibility, preventive guardrails, and behavioral governance for agentic environments. The technology analyzes an agent&#8217;s intended actions in real time, deterministically allowing, modifying, or blocking requests before execution. This approach transitions AI defense from post-incident log analysis to active threat prevention. As detailed in the funding disclosure on Zenity&#8217;s official newsroom, the platform supports both commercial off-the-shelf agents and custom agentic frameworks. Aligning agent guardrails with a GenAI security baseline helps organizations mitigate prompt injection and unauthorized agency across multi-vendor AI deployments.
